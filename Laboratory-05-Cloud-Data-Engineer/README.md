# Laboratory Activity 5 – Mission 5: The Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud data storage and object storage. The activity covers the differences between block, file, and object storage and demonstrates how to deploy MinIO using Docker as an object storage solution.

## Objectives

- Explain the differences between block, file, and object storage.
- Identify appropriate use cases for each storage type.
- Deploy MinIO using Docker.
- Configure MinIO using environment variables.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file to the bucket.
- Document the deployment and reflect on the activity.

## Skills Learned

- Comparing cloud storage types
- Deploying containerized applications
- Configuring Docker containers
- Working with object storage
- Creating buckets and uploading objects
