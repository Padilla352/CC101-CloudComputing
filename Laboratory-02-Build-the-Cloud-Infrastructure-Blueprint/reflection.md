# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think the **compute resource** is the most important cloud infrastructure component because it provides the processing power needed to run applications and services. In the KillerCoda environment, the compute resource included an Intel Xeon CPU with one CPU core and available RAM. Without compute resources, applications and other cloud services would not be able to perform their tasks.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system for servers and cloud environments. During this laboratory, I used Linux commands in KillerCoda to check the operating system, CPU, RAM, storage, mounted file systems, hostname, and IP address. Linux also provides tools that help administrators manage and monitor cloud servers.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure design, resources, configurations, and requirements. It helps prevent mistakes and makes it easier for other team members to understand and maintain the system. Proper documentation can also make troubleshooting easier when problems occur.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using terminal commands. I also learned how to identify compute, storage, networking, and operating system resources. In addition, I learned how to compare AWS, Microsoft Azure, and Google Cloud services and how to create a simple cloud infrastructure diagram.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added a complete cloud infrastructure laboratory with technical documentation, investigation results, screenshots, and a cloud architecture diagram. I also practiced organizing files using Markdown and GitHub. This makes my portfolio more useful because it shows practical skills in cloud computing, Linux administration, documentation, and basic infrastructure design.

## Conclusion

This laboratory helped me understand how different cloud infrastructure components work together. It also gave me practical experience using Linux and GitHub, which are useful skills for future cloud and IT projects.
