# Microsoft Azure

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft.
It provides computing, storage, networking, database, security,
artificial intelligence, and other cloud services.

## Global Infrastructure

Azure provides cloud infrastructure through geographic regions and
availability zones. This infrastructure allows organizations to deploy
applications and services in locations around the world.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create,
configure, monitor, and manage Azure resources and services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtualized computing environments
for running applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of
unstructured data such as documents, images, videos, and backups.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking capabilities for
Azure resources and applications.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users,
applications, and organizational resources.

## Three Advantages

1. Strong integration with Microsoft technologies
2. Global cloud infrastructure
3. Wide range of enterprise services

## Typical Enterprise Use Cases

- Windows Server workloads
- Microsoft 365 integration
- Enterprise applications
- Database systems
- Hybrid cloud environments
