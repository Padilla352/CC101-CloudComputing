# Google Cloud Platform (GCP)

## Brief Overview 

Google Cloud Platform (GCP) is a cloud computing platform provided
by Google. It provides infrastructure, computing, storage, networking,
database, artificial intelligence, machine learning, and other services.

## Global Infrastructure

Google Cloud provides infrastructure across multiple geographic
regions and zones. This allows organizations to deploy applications
and workloads across different locations.

## Cloud Management Console

Google Cloud Console is a web-based interface used to manage Google
Cloud resources, services, projects, and applications.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can be used to run
applications and workloads.

### 2. Cloud Storage

Cloud Storage provides scalable object storage for files, backups,
and other types of data.

### 3. Google Cloud VPC

Google Cloud VPC provides networking capabilities for cloud resources
and applications.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used
to deploy and manage containerized applications.

## Three Advantages

1. Strong artificial intelligence and machine learning capabilities
2. Strong Kubernetes and container support
3. Global infrastructure

## Typical Enterprise Use Cases

- Artificial Intelligence
- Machine Learning
- Data analytics
- Containerized applications
- Kubernetes deployments
