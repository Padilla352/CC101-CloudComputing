# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for the startup because it provides a wide
selection of cloud services that can support a mobile application.
The startup can begin with smaller resources and increase them as the
number of users grows. This allows the company to scale its
infrastructure as its business expands. AWS also provides services
for computing, storage, databases, and application development.

### Recommended Services

1. Amazon EC2
2. Amazon S3
3. Amazon RDS

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice because the university
already uses Windows Server, Microsoft 365, and Active Directory.
Azure provides strong compatibility with Microsoft's existing
technologies and can support hybrid cloud migration. This can make the
transition easier while allowing the university to continue using
familiar Microsoft services. Azure also provides identity, computing,
storage, and networking services.

### Recommended Services

1. Azure Virtual Machines
2. Microsoft Entra ID
3. Azure Storage

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud Platform is a strong choice for the AI research company
because it provides services designed for artificial intelligence,
machine learning, and high-performance workloads. Google Cloud also
provides strong support for data analytics and Kubernetes-based
applications. These capabilities can help the company develop, train,
and deploy AI and machine learning applications. The platform can also
provide scalable computing resources as research requirements grow.

### Recommended Services

1. Compute Engine
2. Vertex AI
3. Google Kubernetes Engine

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable platform for the global e-commerce company because
it provides scalable infrastructure and services for applications
serving users around the world. The company can use load balancing and
automatic scaling to handle changes in customer traffic. AWS also
provides storage and computing services that can support an
e-commerce application. Its global infrastructure can help the company
deploy applications closer to customers in different locations.

### Recommended Services

1. Amazon EC2
2. Elastic Load Balancing
3. Amazon S3
