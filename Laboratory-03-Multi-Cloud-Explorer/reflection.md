## 1. Which Cloud Platform Impressed You the Most?

Among AWS, Microsoft Azure, and Google Cloud Platform, the cloud platform that impressed me the most was Amazon Web Services (AWS). Before doing this activity, I mostly knew AWS as a popular cloud provider, but I did not realize how many different services it offers. While researching AWS, I learned about services such as Amazon EC2, Amazon S3, Amazon VPC, and AWS IAM. Seeing how these services work together helped me understand how companies can build and manage complete IT environments in the cloud.

What I liked about AWS the most is its flexibility. A small startup can start with only the resources it needs and then increase those resources as the number of users grows. At the same time, larger companies can use AWS for more complex systems and applications. This made me realize why scalability is one of the important benefits of cloud computing.

However, this activity also showed me that AWS is not automatically the best choice for every company. Azure can be a better option for organizations that already use Microsoft technologies, while GCP can be a strong choice for companies working with artificial intelligence, machine learning, and Kubernetes. Each provider has its own strengths.

Overall, AWS impressed me because of its wide range of services and flexibility. The most important thing I learned is that choosing a cloud provider should not be based only on popularity. The provider should be selected based on what the organization actually needs.

## 2. What Similarities Exist Among AWS, Azure, and GCP?

AWS, Microsoft Azure, and Google Cloud Platform have many similarities because they all provide the main services needed to build and operate applications in the cloud. During this activity, I noticed that even though the names of their services are different, many of them perform similar jobs. All three providers offer computing, storage, networking, identity management, databases, and Kubernetes services.

For example, AWS has Amazon EC2, Azure has Azure Virtual Machines, and GCP has Compute Engine. These three services allow organizations to run virtual machines in the cloud. For storage, AWS provides Amazon S3, Azure provides Azure Blob Storage, and GCP provides Cloud Storage. There are also similar services for identity management, SQL databases, and Kubernetes.

Another similarity is that all three providers offer scalable infrastructure. This means businesses can increase or decrease their resources depending on their workload. This is useful because a company may not always have the same number of customers or the same amount of traffic. Instead of buying additional physical servers every time the workload increases, companies can use cloud resources that can be adjusted when needed.

AWS, Azure, and GCP also have global infrastructure that allows organizations to deploy applications in different geographic locations. Each provider also has a management console where users can create, configure, and monitor their cloud resources.

Even though the three platforms are similar, they have different strengths. AWS has a broad range of services, Azure has strong integration with Microsoft technologies, and GCP is strong in AI, machine learning, and Kubernetes. Learning these similarities and differences helped me understand why companies have several cloud providers to choose from.

## 3. How Do Business Requirements Influence Cloud Platform Selection?

Business requirements have a major influence on which cloud platform an organization should choose. From this activity, I learned that there is no single cloud provider that is perfect for every company. Before choosing a platform, a business needs to consider its existing technology, budget, applications, security requirements, number of users, scalability needs, and future plans.

The client scenarios in this mission made this easier to understand. For example, the university already uses Windows Server, Microsoft 365, and Active Directory. Because the university already depends on Microsoft technologies, Azure would be a practical choice because of its strong Microsoft integration. This could make the migration process easier for the university.

The AI research company has a completely different requirement. It needs high-performance computing for artificial intelligence and machine learning applications. In this situation, Google Cloud Platform would be a good option because of its capabilities in AI, machine learning, and Kubernetes.

The startup company also has different needs. Since its budget is limited but it expects rapid growth, it needs a platform that can provide scalable services without requiring a large investment in physical infrastructure. AWS can provide services that allow the startup to begin small and increase its resources as the application grows.

For the global e-commerce company, availability and automatic scaling are very important because customers may access the website from different parts of the world and traffic can change quickly. A cloud provider with global infrastructure and scalable services would therefore be appropriate.

This activity taught me that cloud selection should always start with the client's requirements. Understanding the business problem first makes it easier to determine which technology can provide the best solution.
