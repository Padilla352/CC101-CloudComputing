## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is generally considered to offer one of the broadest portfolios of
cloud services among the three major providers. Its large collection
of computing, storage, database, networking, security, analytics, and
other services makes it suitable for many different workloads.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations that already
depend heavily on Microsoft technologies. It works closely with
technologies such as Windows Server, Microsoft 365, and Microsoft
Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for organizations focused on Artificial
Intelligence, Machine Learning, and Kubernetes. Google Kubernetes Engine
is particularly important for organizations deploying containerized
applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because of its broad selection of cloud
services and flexibility. It provides many options for computing,
storage, databases, networking, and application development, making it
useful for different types of projects and organizations.
